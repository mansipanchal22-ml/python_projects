# Titanic Survival Analysis Project

## Project Overview
This project analyzes the Titanic passenger dataset to understand passenger survival patterns using Python, Pandas, Matplotlib, and Seaborn.

## Project Files
- `Titanic_Analysis.ipynb` — Python code, data analysis, and graphs.
- `train.csv` — Titanic dataset used for analysis.
- `README.md` — Project documentation.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Dataset inspection
- Missing value analysis and handling
- Duplicate value checking
- Survival count visualization
- Survival analysis by gender
- Survival analysis by passenger class
- Age and fare distribution
- Correlation heatmap

## How to Run
1. Install Python and Jupyter Notebook.
2. Keep `Titanic_Analysis.ipynb` and `train.csv` in the same folder.
3. Open `Titanic_Analysis.ipynb` in Jupyter Notebook.
4. Run the notebook cells in order.

## Dataset
The project uses the Titanic training dataset, `train.csv`.

## Conclusion
This project explores the Titanic dataset and visualizes patterns related to passenger survival.
